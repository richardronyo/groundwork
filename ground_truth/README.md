
# Ground Truths Generator

This folder contains the automated pipeline for scraping raw nopCommerce documentation, processing the text, and using OpenAI's API to extract concise, structured "Ground Truth" statements for evaluation and training purposes.

---

## File & Directory Overview

* **`generate_ground_truth.py`**
  A Python script that reads the scraped JSON documentation (`nopcommerce_docs_raw.json`) and uses OpenAI's API to extract atomic, two-column ground truth statements (`Area` and `Ground Truth`).
* **`ground_truth.csv`**
  The final generated CSV file containing all processed ground truth pairs extracted from the documentation.
* **`ground_truths_archive/`**
  Contains older ground truth samples previously used by the team. *Note: The structure and format of `ground_truth.csv` was directly inspired by these older samples.*
* **`nopCommerce-Docs/`**
  The cloned local git repository containing the raw Markdown files from the official nopCommerce documentation.
* **`nopcommerce_docs_raw.json`**
  An intermediate JSON file generated by `scrape_docs.py` that consolidates all raw documentation titles and text into a structured format.
* **`requirements.txt`**
  List of Python dependencies required to run the scraping and generation scripts.
* **`scrape_docs.py`**
  A Python script that iterates through the local `nopCommerce-Docs/` directory to scrape, clean, and consolidate raw documentation content into `nopcommerce_docs_raw.json`.

---

## How to Run the Pipeline

Follow these step-by-step instructions to set up your environment, scrape the documentation, and generate the ground truths CSV file.

### Step 1: Set Up Python Virtual Environment

Create a new virtual environment or use an existing one in your parent directory, then install the dependencies:

```bash
# Option A: Create a new venv inside this directory
python -m venv .venv
source .venv/bin/activate  # On Windows use: venv\Scripts\activate

# Option B: Use an existing venv from the parent directory
source ../.venv/bin/activate

# Install required dependencies
pip install -r requirements.txt
```

### Step 2: Clone the nopCommerce-Docs Repository


Clone the official documentation repository into this directory using either HTTP or SSH:

```bash
# Option A: HTTPS
git clone https://github.com/nopSolutions/nopCommerce-Docs.git

# Option B: SSH
git clone git@github.com:nopSolutions/nopCommerce-Docs.git
```

### Step 3: Run the Documentation Scraper


Execute the scraping script to process the cloned documentation files:

```bash
python scrape_docs.py
```

* **Expected Output:** You will see log messages in your terminal indicating that files in `nopCommerce-Docs/` are being processed. A new file named `nopcommerce_docs_raw.json` will be generated. You can open and inspect this file to verify that document titles and raw text were correctly parsed.


### Step 4: Export OpenAI API Key


Set your OpenAI API key as an environment variable:

```bash
export OPENAI_API_KEY="your-actual-api-key-here"
```
> **Note for Windows PowerShell:** Use `$env:OPENAI_API_KEY="your-actual-api-key-here"` instead.


### Step 5: Generate Ground Truths


Run the main extraction script to process the raw JSON via OpenAI:

```bash
python generate_ground_truth.py
```

* **Expected Output:** Terminal output will show progress logs for each document being processed (e.g., `[1/50] Extracting ground truths for: Order Settings...`). Once complete, `ground_truth.csv` will be created or updated. Inspect `ground_truth.csv` to ensure it contains the `Area` and `Ground Truth` columns filled with structured data.
